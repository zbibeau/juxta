Odaiji × JuxtaLink

Installation, vérification et dépannage du lecteur de cartes sur votre poste.

Télécharger le kit Windows Télécharger le kit Mac
Windows — 3 étapes
  1. Clic droit sur le fichier téléchargé → Extraire tout…
  2. Ouvrir le dossier extrait → double-clic sur Installer-Odaiji-Juxta.bat (nouveau poste) ou Diag-seul.bat (poste déjà équipé) → accepter la fenêtre Windows.
  3. Quand le script le demande : insérer CPS + Vitale, faire une lecture dans Odaiji, puis Entrée. Le rapport apparaît sur le Bureau.
Mac — 3 étapes
  1. Double-clic sur le zip téléchargé pour l'extraire, puis ouvrir le dossier.
  2. Ouvrir Terminal, taper cd (avec un espace), glisser le dossier dans la fenêtre, Entrée, puis coller :
    chmod +x *.command *.sh && xattr -dr com.apple.quarantine .
  3. Double-clic sur Installer-Odaiji-Juxta.command (nouveau poste) ou Diag-seul.command (poste équipé) → mot de passe admin. Quand le script le demande : CPS + Vitale insérées, lecture dans Odaiji, puis Entrée.
