Odaiji × JuxtaLink

Installer, dépanner et vérifier le lecteur de cartes (CPS + Vitale) sur un poste médecin.

Télécharger le kit Windows

Quel fichier lancer ?

Extraire le zip d'abord (clic droit → Extraire tout…). Dans le dossier extrait, les deux fichiers du quotidien sont en tête de liste : 1 pour installer, 2 pour dépanner.

Ce qu'il vous reste à faire

    Les autres fichiers du kit (équipe, sur indication du rapport)

    Cartes insérées, hors consultation, depuis la session de l'utilisateur habituel du poste. Après chaque passage, envoyer au support MadeForMed les fichiers du Bureau : Avant_…txt, Apres_…txt et, pour le dépannage, Depannage_…txt.
