RAPPORTS TRANSMIS, CLE D'ENVOI, FILE D'ATTENTE
  Chaque rapport / journal du kit part automatiquement chez MadeForMed (message "transmis automatiquement" a la fin).
  Pas d'Internet au moment de l'envoi : le rapport est mis en FILE D'ATTENTE (C:\ProgramData\MadeForMed\spool) et repart tout seul
  au prochain passage du kit. Cle d'envoi du cabinet : fichier cle-envoi.txt (fourni par MadeForMed, une ligne) a poser dans le dossier
  du kit ou dans C:\ProgramData\MadeForMed. Sans cle, les rapports partent "non identifies". Identifiant du poste (Poste ID) :
  C:\ProgramData\MadeForMed\poste-id.txt (cree automatiquement, identique d'un rapport a l'autre).
  Donnees envoyees : le rapport tel que ecrit sur le Bureau (codes CPS, base64, FINESS / numero PS et NIR sont masques). Aucun fichier du medecin.

SENTINELLE (surveillance passive, optionnelle)
  Installer-Sentinelle.bat cree la tache \Odaiji\Sentinelle (SYSTEM, tous les jours 12:30 + 10 min apres le demarrage, priorite basse).
  Elle lance le diagnostic en mode leger (-Leger) : AUCUNE reparation, AUCUN acces au lecteur ni aux cartes, aucun fichier sur le Bureau.
  Elle envoie un petit battement (scenario, constats, version) et le rapport complet seulement si l'etat change (ou une fois par semaine).
  Elle ne se met jamais a jour toute seule : MadeForMed voit les kits en retard. Pause : sentinelle.off ; retrait : Desinstaller-Sentinelle.bat.

JUXTALINK ET L'UAC
  JuxtaLink exige les droits administrateur ("Voulez-vous autoriser cette application...").
  Lance automatiquement au demarrage de Windows, il est BLOQUE en silence -> apres un redemarrage du PC,
  plus de JuxtaLink et "carte Vitale non lue". Le kit cree la tache planifiee \Odaiji\JuxtaLink
  (ouverture de session, privileges eleves) : JuxtaLink demarre sans question. Pour le relancer a la main :
  icone "JuxtaLink (Odaiji)" sur le Bureau. Le compte du medecin doit etre administrateur du poste.

SMART APP CONTROL (Windows 11)
  S'il est actif, Windows bloque mica.dll (non signe) : erreur 0xc0e90002, Vitale illisible.
  En mode evaluation, Windows l'active seul quelques jours plus tard. Le diag le signale.
  Correction manuelle : Parametres > Confidentialite et securite > Securite Windows >
  Controle des applications et du navigateur > Smart App Control > Desactive. Prevenir le medecin
  (non reactivable sans reinstaller Windows sur la plupart des versions).

ERREURS DRC A LA TELETRANSMISSION (Chrome 142+ / Edge / Firefox 145+ "Local Network Access")
  Autoriser-Odaiji-Chrome.bat ecrit la politique LocalNetworkAccessAllowedForUrls (Chrome + Edge ;
  Firefox : SkipDomains ; tous utilisateurs). Remplace chrome://flags, survit aux mises a jour.
  Relancer le navigateur. Verifier : chrome://policy. Integre a l'installation (etape 4b).

ANCIENS LOGICIELS METIERS (Cegedim, Affid, Shaman, Weda...)
  Installeur / Reparer-interactif : "Le medecin facture-t-il ENCORE avec ... ?"
    n = lancement coupe, puis produits MSI de l'editeur desinstalles un par un (sans redemarrage, hors briques
        partagees FSV/Cryptolib/MICA/GALSS/Java/.NET, arret si TeamViewer/JuxtaLink/DMP Connect/MICA disparait),
        dossiers de l'editeur deplaces dans C:\_Odaiji_a_supprimer (a vider apres validation).
        Desinstalleurs non-MSI : listes dans le rapport, a retirer avec le support.
    o = rien n'est modifie.
  Neutraliser-Ancien-Logiciel.bat (EQUIPE, a la demande) : liste le catalogue (editeurs.psd1) et ce qui est detecte sur le poste,
    puis : numero du logiciel > N (neutralisation seule : demarrage, services, taches, processus ; rien n'est desinstalle, recommande)
    ou D (+ desinstallation MSI, dossiers en quarantaine ; jamais propose pour les logiciels medicaux du catalogue ni sur le poste
    qui heberge la base). Le moteur montre ce qui sera coupe et demande confirmation. R = remettre en route un logiciel neutralise ;
    S = remettre en route les elements Windows / Adobe coupes a tort. Rapport : Neutralisation_<poste>_<date>.txt sur le Bureau.
    -Simulation (powershell -File Neutraliser-Ancien-Logiciel.ps1 -Simulation) : affiche sans rien executer.
  Neutraliser-Cegedim.bat : ancien raccourci, Cegedim seulement (meme moteur que l'outil ci-dessus et que l'installeur).
  Journal : C:\ProgramData\MadeForMed\CegedimNeutralise (un fichier par logiciel). Retour arriere : R.
  Nettoyage.bat : avec le support uniquement. Prise en main a distance jamais touchee.

Si la neutralisation d'un ancien logiciel (Neutraliser-Cegedim) a desactive des elements Windows / Adobe (kit v0.3.29 a v0.3.31 :
taches « Synchronize... », service OneSyncSvc, « Adobe Acrobat Synchronizer ») : clic droit sur Neutraliser-Cegedim.ps1 > Executer avec PowerShell
ne suffit pas : lancer Neutraliser-Ancien-Logiciel.bat puis S, ou en administrateur :  powershell -File Neutraliser-Cegedim.ps1 -Restaurer -Systeme
(remet en route seulement les elements Windows / Microsoft / Adobe ; les elements de l'ancien logiciel restent neutralises).

GARDIEN (v0.3.50)
  Gardien-JuxtaLink.ps1 : veille de JuxtaLink toutes les 10 min (tache planifiee \Odaiji\Gardien-JuxtaLink, compte SYSTEM).
  JuxtaLink ferme ou plante -> relance dans la session du medecin, sans UAC. Pose par 1-Installer, 2-Depanner et Demarrage-JuxtaLink.bat.

  Journal : C:\ProgramData\MadeForMed\Gardien\gardien.log (a envoyer avec les rapports). Retrait : Demarrage-JuxtaLink.bat -Retirer.

ENVOI AUTOMATIQUE DU RAPPORT
Quand un rapport montre un probleme qui reste (un [KO]) ou un cas inconnu, il est transmis automatiquement a MadeForMed
(nom du poste, liste des logiciels et resultats des controles ; aucune donnee patient). Aucune question n'est posee.
Si l'envoi echoue (pas de reseau), le message demande de recuperer le fichier par le transfert de fichiers TeamViewer.
